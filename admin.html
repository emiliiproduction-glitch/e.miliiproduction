Private editing page

人米網站內容管理

這裡用來整理網站文字、作品資料、圖片路徑與素材上傳。後台不會出現在公開導覽列；真正能寫回網站的是你的 GitHub token，所以 token 不要貼到聊天或任何文件裡。

現在版本：先管理 `content/site.json` 與圖片素材。已串接這份資料的頁面會跟著更新；還沒串接的舊 HTML 頁面，需要我再逐頁接上。

安全提醒：Token 只在這個瀏覽器送到 GitHub API，不會寫進網站檔案。用完可按「清除 token」。

Site

品牌與首頁

修改網站名稱、首頁主視覺文字與團隊介紹。圖片欄位填網站內的相對路徑，例如 `artist_cv_assets/production_media/beneath/beneath-stage-01.jpg`。

About

團隊介紹

一段一格，後台會存成段落。請保留乾淨、正式、適合品牌網站的語氣。

Productions

作品列表

用來管理作品年份、作品名稱、頁面路徑和對外連結。之後作品集總頁可完全改成讀這裡的資料。

Images

首頁劇照資料

管理 `site.json` 裡的圖片清單。這裡改的是圖片路徑與說明，不會自動裁切圖片。

Upload

上傳圖片到 GitHub

選擇圖片後，填入你想放在網站裡的路徑，再用 token 上傳。上傳成功後，把路徑貼到作品或圖片欄位。

尚未選擇圖片
圖片會上傳到 GitHub repo，Vercel 部署完成後才會在公開網站顯示。

Data

讀取與匯出

如果你用 `file:///` 開啟後台，瀏覽器可能讀不到 `site.json`，可以手動選檔。使用本機伺服器或正式網址時會自動讀取。
